# Tenet Hack 2025

## About Tenet Hack 2025

Tenet Hack is the first edition of an annual hackathon organized by the IOIT ACM Student Chapter.
This repository contains the source code for the official event website.

## Development

### Prerequisites

- [Node.js](https://nodejs.org/)
- [pnpm](https://pnpm.io/) package manager

### Setup

1. Clone the repository:

```sh
git clone https://github.com/IOIT-ACM/hackathon && cd hackathon
```

2. Copy the environment file:

```sh
cp .env.example .env
```

Fill in the required environment variables.

```sh
Install dependencies:
pnpm install
```

Start the development server:

```sh
pnpm run dev
```

Open http://localhost:3000
